# Decompile Analysis

This folder contains all static analysis outputs from Ghidra/REA:

- strings.txt - All extracted strings
- imports.txt - Import table
- headers.txt - PE headers
- rsrc.raw - Resource section
- extracted_mz.bin - Embedded MZ found in resources
- cleaned_pseudocode.c - Cleaned up decompilation
- all_functions.c - All decompiled functions
- metadata.json - Analysis metadata
